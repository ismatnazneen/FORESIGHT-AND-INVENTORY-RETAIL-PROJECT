# FORESIGHT & INVENTORY MANAGEMENT

## Project Overview

Foresight & Inventory Management is a data analytics and machine learning project designed to analyze sales data, forecast future demand, and improve inventory management.

## Objectives

- Analyze historical sales data
- Forecast future product demand
- Identify inventory trends
- Identify products that need reordering
- Analyze product and category performance
- Create interactive Power BI dashboards

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Prophet
- Jupyter Notebook
- Power BI

## Project Workflow

1. Data Collection
2. Data Cleaning
3. Exploratory Data Analysis
4. Feature Engineering
5. Demand Forecasting
6. Inventory Analysis
7. Power BI Dashboard

## Key Features

- Sales trend analysis
- Demand forecasting
- Product performance analysis
- Inventory monitoring
- Reorder identification
- Interactive Power BI dashboard

## Project Outcome

The project helps businesses understand sales patterns, forecast future demand, and make better inventory and stock-reordering decisions.
